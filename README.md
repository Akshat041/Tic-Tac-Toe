# Tic-Tac-Toe Game

## Description

This is a simple Tic-Tac-Toe game implemented using HTML, CSS, and JavaScript. It features a classic 3x3 grid where two players can take turns marking spaces with "X" or "O". The game includes:

- Player name input for a personalized experience.
- Modal dialogs for player setup and announcing the winner.
- Clear game logic to determine the winner or detect a draw.
- A clean and responsive user interface.

## Features

- **Two-Player Game:** Supports two human players.
- **Player Name Input:** Prompts players to enter their names before starting the game.
- **Winner Announcement:** Displays a modal dialog with the winner's name when the game ends.
- **Draw Detection:** Detects and announces a draw if all squares are filled without a winner.
- **Responsive Design:** The game board adapts to different screen sizes.
- **Clear Visuals:** Uses a clean design for the board and modals.

## How to Play

1.  **Clone the Repository:**
    ```bash
    git clone git@github.com:Akshat041/Tic-Tac-Toe.git
    cd tic-tac-toe
    ```
2.  **Open in Browser:** Open the `index.html` file in your web browser.
3.  **Enter Player Names:** The game will prompt you to enter names for Player 1 and Player 2.
4.  **Take Turns:** Players alternate turns clicking on the empty squares to place their marks ("X" or "O").
5.  **Win or Draw:** The game ends when one player has three in a row (horizontally, vertically, or diagonally) or all squares are filled. The winner is announced in a modal dialog, or a draw is declared.
6.  **Play Again:** After a game ends, you can restart and play again.
